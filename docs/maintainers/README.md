# Maintainer Materials

These documents turn the public repository into a repeatable launch and release
process.

- [Launch Campaign](launch-campaign.md): positioning, audience, channels, copy, cadence, and metrics
- [Demo and Recording Script](demo-script.md): 30-second, 90-second, and technical demo flows
- [Release Checklist](release-checklist.md): technical, security, repository, and communication gates
- [PyPI Trusted Publishing](trusted-publishing.md): OIDC publisher setup, approvals, and bootstrap-token retirement
- [Public Repository Cutover](public-repository-cutover.md): clean history generation, archive preservation, and launch verification

The campaign is designed for a self-hosted open-source product. It must never
imply that T54 Labs operates a public shared Relay or that a private Team Relay
is suitable for untrusted multi-tenancy.
